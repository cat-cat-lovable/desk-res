# Separator

Separador visual. Para dividir secciones.

## Cuándo usarlo

Para marcar un límite entre zonas cuando el aire no basta: menús, toolbars, metadatos en línea. Primero prueba con espacio — la línea es el recurso de segunda instancia.

## Composición

Una sola pieza (`Separator`) con orientación horizontal o vertical. Decorativa por defecto: los lectores de pantalla la ignoran.

## Uso básico

```tsx
<Separator />
```

## Reglas

- Usa Separator según el propósito descrito.
- No abuses de este componente en contexts donde no aplica.

## Import

```tsx
import { Separator } from "@/shared/components/base/Separator";
```
